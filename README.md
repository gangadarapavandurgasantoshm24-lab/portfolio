# Santosh Portfolio

Personal portfolio website for Maddukuri Gangadara Pavan Durga Santosh, showcasing education, skills, projects, experience, achievements, contact details, and resume.

## Project Structure

```text
portfolio/
├── assets/
│   ├── Santosh_Resume.pdf
│   ├── santosh.jpg
│   └── project and contact images
└── website/
    ├── index.html
    ├── style.css
    └── script.js
```

## Features

- Responsive portfolio home page
- About, skills, projects, experience, and contact sections
- Resume button linked to `assets/Santosh_Resume.pdf`
- Animated hero typing effect
- Particle background effect
- Organized assets and website source files

## Open Locally

Open this file in a browser:

```text
website/index.html
```
