## Key Highlights & Featured Projects

1. **Click2Book – Online Ticket Reservation System**  
   *React.js, Node.js, Express.js, PostgreSQL, REST APIs*  
   Full-stack reservation application featuring trip search, seat selection, booking lifecycle, cancellation handling, file uploads, and PostgreSQL persistence.

2. **SmartSlot AI – Intelligent Multi-Warehouse Management & Optimization**  
   *React, React Three Fiber, Node.js, Vite, Dijkstra, A\*, Nearest Neighbor, 2-opt, SSE*  
   **🏆 1st Prize Winner at Utkrishta 2026 Hackathon (Neural Forget Track 2).** 3D warehouse floorplans, multi-stop picking route optimization, and real-time state synchronization.

3. **PricePilot – Intelligent Multi-Store Price Comparison Platform**  
   *JavaScript, Node.js, Express.js, Playwright, REST APIs, HTML, CSS*  
   Unified search engine comparing product listings, computing variant-aware payable prices with fees and instant discounts, and cashback/EMI breakdowns.

4. **SmartAgriculture – AI-Based Plant Disease Detection System**  
   *Python, TensorFlow, Keras, CNN, MobileNetV2, EfficientNetB0, OpenCV, Streamlit, Grad-CAM*  
   Deep learning classification across 66 classes and 20 crop types with Grad-CAM explainability heatmaps and pesticide recommendation logic.

5. **Cricket Ball Tracking and Trajectory Analysis**  
   *Python, OpenCV, YOLO11, Computer Vision, NumPy, Pandas*  
   Research under Dr. S. Manipriya at IIIT Sri City. Custom YOLO11n detection, temporal tracking, direction consistency filtering, and high-precision bat-contact localization.

## Open Locally

Simply open `website/index.html` in any modern web browser or serve via:

```bash
# Using Python
python -m http.server 8080
# Visit http://localhost:8080/website/index.html
```

## Deployment

Configured for zero-config Vercel deployment via `vercel.json` with URL rewrites for `/`, `/style.css`, `/script.js`, and `/assets/*`.
